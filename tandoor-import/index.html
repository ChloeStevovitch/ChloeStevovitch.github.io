🍲 Import Tandoor

Interface autonome — tourne dans ce navigateur. Les photos ne sont envoyées qu'à l'API Claude (analyse) et, sans photo du plat, une recherche d'image est faite sur Wikimedia / Pollinations.

Connexion

📷 Photos de la recette

Ajoute une ou plusieurs photos (pages de livre, notes, photo du plat…). Claude extrait le texte, le traduit en français et remplit le JSON ci-dessous pour que tu le relises.

📋 JSON de la recette

Pré-rempli avec la dernière recette. Modifie librement avant d'importer.

🖼️ Image de la recette

Après l'analyse, une image est proposée : la photo du plat si tu en as fournie une, sinon une photo libre trouvée sur Wikimedia Commons, sinon une image générée. Tu peux aussi choisir ton propre fichier.

Le token Tandoor et la clé API sont stockés uniquement dans ce navigateur (localStorage). Le token n'est envoyé qu'à ton serveur Tandoor, la clé qu'à api.anthropic.com.
