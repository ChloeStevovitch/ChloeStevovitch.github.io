🍲 Import Tandoor

Interface autonome — tourne dans ce navigateur. Les photos ne sont envoyées qu'à l'API Claude (analyse) et, sans photo du plat, une recherche d'image est faite sur Wikimedia / Pollinations.

Connexion

📷 Photos de la recette

Ajoute une ou plusieurs photos (pages de livre, notes, photo du plat…). Claude extrait le texte, le traduit en français et remplit le JSON ci-dessous pour que tu le relises.

✏️ Modifier la recette

Décris le changement voulu ; Claude adapte les ingrédients et les instructions du JSON ci-dessous. Tu peux enchaîner plusieurs modifications.

📋 JSON de la recette

Pré-rempli avec la dernière recette. Modifie librement : l'aperçu à droite se met à jour.

🥗 Apports nutritionnels

Estimation par Claude à partir des ingrédients et quantités du JSON (tables de composition usuelles). Calculée automatiquement après l'analyse ou une modification ; indicatif, pas une valeur médicale.

🖼️ Image de la recette

Après l'analyse, une image est proposée dans l'aperçu : la photo du plat si tu en as fournie une, sinon une photo libre trouvée sur Wikimedia Commons, sinon une image générée.

📎 Ajouter l'image à une recette existante

Facultatif : envoie seulement l'image courante à une recette déjà présente dans Tandoor (« Tout envoyer » crée, lui, une nouvelle recette avec son image).

Le token Tandoor et la clé API sont stockés uniquement dans ce navigateur (localStorage). Le token n'est envoyé qu'à ton serveur Tandoor, la clé qu'à api.anthropic.com.
