Import Tandoor

Remplissez vos recettes ci-dessous, puis envoyez-les directement dans votre instance Tandoor. Tout part de votre navigateur : rien n'est stocké ni relayé par un serveur intermédiaire, et aucun identifiant n'est écrit dans le code de cette page.

Cet outil ne lit pas de photos automatiquement. Si vous partez de photos de recettes, demandez d'abord à Claude (dans une conversation classique) de les convertir au format JSON décrit plus bas, puis collez le résultat ici.

1. Connexion à Tandoor

Le jeton est stocké uniquement dans le stockage local de votre navigateur (localStorage) — il n'en sort que pour être envoyé à l'URL Tandoor indiquée ci-dessus. Utilisez de préférence un jeton dédié à cet usage.

Si les requêtes échouent avec une erreur réseau, votre serveur Tandoor doit autoriser les requêtes envoyées depuis (réglage CORS_ALLOWED_ORIGINS côté Tandoor).
